# PRODUCT_REQUIREMENTS.md

## 目的

`blog-pet` は、ペットシッターの日常の活動報告とサービス案内を通じて、依頼を検討する人にサービスの内容と人柄を伝えるサイトです。

## 利用者

- 公開閲覧者: サービス内容と活動報告を確認する。
- 管理者: サイト設定と公開フローを管理する。
- 投稿者・編集者: Sanity Studio で記事と固定ページを編集する。

## MVP

トップ、ご利用方法、料金、スタッフ、ブログ、アクセス・対応エリア、お問い合わせ、404、RSS、sitemap、robots.txt を対象にします。公開済みコンテンツだけを静的生成します。

固定ページ、記事、カテゴリー、スタッフ、サイト設定は #3 で実装し、公開ページは #4 で実装します。

独自バックエンド、閲覧者アカウント、コメント、予約、決済は対象外です。

## 配信と運用の要件

- Sanity Studio で活動報告とサービス案内を編集し、公開済みコンテンツだけを Astro のビルド時に取得する。
- 公開サイトと Studio は GitHub Actions で別々にビルドし、S3 と CloudFront から配信する。
- Sanity の publish / unpublish webhook を受けて、公開サイトを再デプロイできる。
- 下書きが公開サイトに含まれず、本番ビルドで Sanity の取得失敗をフォールバックコンテンツで隠さない。
- シークレットを公開物へ含めず、独自バックエンドや公開サイト用の実行時データベースを持たない。
- SEO、表示速度、ローカル開発のしやすさ、運用コストの低さを維持する。

## MVP の受け入れ条件

- 活動報告とサービス案内を Sanity Studio で管理し、公開済みの内容を静的ページに反映できる。
- S3 と CloudFront に公開サイトと Studio をデプロイできる。
- canonical、OGP、sitemap、RSS、robots.txt、404 の動作を確認できる。
- ドキュメントに従ってローカル起動とデプロイができる。
