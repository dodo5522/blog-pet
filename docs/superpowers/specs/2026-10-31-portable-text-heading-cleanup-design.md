# Portable Text 見出し表示の整理

## 目的

Sanity 上で既存本文の h1 を h2 に書き換え済みのため、公開側に残る h1 から h2 への互換変換を削除する。見出しに Markdown 記法風の `##` / `###` が付く表示も取り除き、見出し文字列そのものを表示する。

## 範囲

- 対象: Portable Text の見出しレンダリング、見出し ID と目次、共通見出し CSS、コンテンツモデル文書。
- 対象外: Sanity のデータ変更、見出しの文字サイズ・色・余白の再設計、Studio で選べる見出しレベルの変更。
- 制約: ページタイトルを h1 とする現在の構造、h2/h3 のアンカーと目次、重複見出し ID の一意性を維持する。

## 方式

1. レンダラーの旧 h1 対応を残す。実装は変わらないが、全記事を h2 に更新済みという運用状態とコードがずれ続けるため採用しない。
2. レンダラーから h1 の収集・ID割り当て・出力変換を除き、h2/h3 の処理を保つ。CSS の疑似要素による Markdown 記号表示を外す。現在のデータ状態と表示上の要望に一致し、変更箇所も限定できるため採用する。

## 完了条件

- 旧本文 h1 を h2 として出力・目次化する互換処理がない。
- Portable Text の見出しに Markdown 記法風の接頭表示がない。
- h2/h3 の ID、目次、重複時の ID サフィックスが維持される。
- コンテンツモデル文書に旧 h1 互換動作の説明が残っていない。
