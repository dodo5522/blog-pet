# 猫と暮らす人に親しみやすいサイトデザイン

## 意図

ペットシッターを検討する人が、サービスの安心感を保ったまま、猫との日々を感じる温かいサイトにする。現行の静的 Astro サイトと各案内ページの構成を生かし、依存を増やさず CSS と既存コンポーネントを中心に整える。

## アプローチ

1. **ひだまりの暮らしを軸にする（採用案）** — 生成り色、若草色、淡い日なた色と猫の写真で、自然で安心できる印象にする。サービス情報と活動報告の両方になじむ。
2. **猫の案内役を加える（比較用の第2コミット）** — 第1案の上に、小さな猫のイラスト風モチーフを控えめに加える。第1案との差分だけを独立コミットにし、採用判断を見比べられるようにする。
3. **猫と暮らす家の読みものにする** — クリーム色、濃いブラウン、テラコッタで雑誌のように整える。記事には合うが、案内サイト全体の温かさは第1案より弱い。

## 目標と範囲外

- ホーム、案内ページ、活動報告、記事一覧で色・余白・写真の扱いを一貫させる。
- 猫の写真を主役にし、問い合わせや利用方法への導線、文章の読みやすさを保つ。
- 第1コミットをベースデザイン、第2コミットをイラスト風モチーフ追加として分離する。
- 画像が未設定でもレイアウトが成立するようにする。
- 大きなキャラクター表現、アニメーション、CMS変更、依存追加、機能変更は行わない。

## 制約

- Astro の静的生成、Sanity のビルド時取得、S3 + CloudFront 配信を維持する。
- アクセシビリティ、モバイル表示、既存 SEO とリンク構造を損なわない。
- 既存コンテンツを写真素材として使えるかは実装時に確認し、使えない箇所は既存の表示を維持する。

## 実装者に残す判断

写真を使うページとトリミング、視認性を保つ色の具体値、イラスト風モチーフの実装方法は、既存データと各ページを確認して決める。最終的に2コミット間の画面差を比較できる状態にする。
